Déposer des fichiers

  1. Cliquez sur « Déposer des fichiers » : la page de dépôt Nextcloud s'ouvre dans un nouvel onglet.
  2. Nommez vos fichiers selon la convention de nommage.
  3. Glissez vos fichiers dans la page ou cliquez pour les choisir. Aucun compte n'est requis.
  4. Une fois le dépôt terminé, avisez Maggie par courriel.

Convention de nommage

Chaque fichier du portail suit le même modèle. Nommez vos fichiers de la même façon avant de les déposer.

PEI_Campagne_Langue_Format_Type_Date_vN.ext

  • Les champs sont séparés par « _ »; les mots d'un même champ sont reliés par « - ». Pas d'espaces ni d'accents.
  • Toujours le même ordre. Un champ qui ne s'applique pas est omis.
ChampValeurs
PEIToujours en premier (Poulin Électrique Inc).
CampagneIO1-Generac, IO2-Poulin, FB-Generac-Service (publicité Facebook), Evanov (tout le portail).
LangueFR, EN ou BI (bilingue).
FormatLargeur x hauteur en pixels : 300x250, 1920x1080.
TypeOmis pour un créatif. FINAL (version finale déposée), Proof-Static, Proof-Video, Poster, CreativeList, Display (ZIP), Logo-Horse.
DateAAAA-MM-JJ (ou AAAA-MM).
Versionv2, v3… La première version n'a pas de numéro.
