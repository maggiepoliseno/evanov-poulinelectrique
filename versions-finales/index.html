Déposer des fichiers

  1. Cliquez sur « Déposer des fichiers » : la page de dépôt Nextcloud s'ouvre dans un nouvel onglet.
  2. Glissez vos fichiers dans la page ou cliquez pour les choisir. Aucun compte n'est requis.
  3. Une fois le dépôt terminé, avisez Maggie par courriel.
